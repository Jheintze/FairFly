
# FairFly

A responsive travel agency landing page built with HTML and CSS.

## About

FairFly is a fictional travel agency offering complete travel packages, including flights, accommodation, and selected activities.

This project was created as part of the Mayerfeld AI-Assisted Frontend Developer Practicum.

## Features

- Responsive single-page layout
- Travel package cards with destinations, durations, and prices
- Customer testimonials
- Travel planning call-to-action
- Semantic HTML5 structure
- CSS Grid and Flexbox layouts

## Technologies

- HTML5
- CSS3
