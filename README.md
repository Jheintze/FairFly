# FairFly

A responsive travel agency landing page built with React, Vite, and Tailwind CSS.

## About

FairFly is a fictional travel agency offering complete travel packages, including flights, accommodation, and selected activities.

This project is being developed as part of the Mayerfeld AI-Assisted Frontend Developer Practicum and is currently in progress.

## Features

- Responsive single-page layout
- Travel package cards with destinations, durations, and prices
- Region-based filtering of travel packages
- Interactive traveler counters with dynamic price calculation
- Customer testimonials
- Travel planning call-to-action
- Responsive navigation with a mobile hamburger menu

## Technologies

- React
- Vite
- Tailwind CSS
- JavaScript
